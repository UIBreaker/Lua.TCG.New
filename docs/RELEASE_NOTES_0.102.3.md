# Terra Suit — beta 0.102.3 cho Android

APK chứa đầy đủ nội dung từ commit `dcbddc0392b5f4e0d674036c34337834250681ac`, chỉ đổi nhãn menu thành **beta 0.102.3**.

- Hệ thống và hiệu ứng nổ Cái Giường.
- Mở rộng nội dung rương, SPN dị thường và ảnh cho các ấn bản mới.
- Bao gồm các tính năng, hiệu ứng hành động và phần thưởng của bản trước.
- Giữ màn hình ngang, tràn viền, điều khiển cảm ứng và vuốt kho.

Tải `LUA-TCG-0.102.3-Android.apk`, mở file và chọn **Cập nhật**. Dùng cùng khóa ký với APK trước, versionCode 10203. Không gỡ bản cũ để giữ save.

Yêu cầu Android 6.0 trở lên; hỗ trợ ARM64 và ARMv7. Đã đối chiếu 109 file Lua/shader với commit gốc và kiểm tra danh sách 804 file runtime; chữ ký, nổ Giường, rương, ấn bản, SPN dị thường, shader và cảm ứng đều qua kiểm tra. Chưa thử trên điện thoại Android thật.
