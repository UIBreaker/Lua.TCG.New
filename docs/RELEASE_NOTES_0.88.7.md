# Terra Suit — beta 0.88.7 cho Android

APK đóng gói đầy đủ nội dung từ commit `4198dda8af312f7d0bc2a5fb8c905585cae76234`, chỉ cập nhật nhãn menu thành **beta 0.88.7**.

- Hiệu ứng hành động mới và tinh chỉnh hiệu ứng chiến đấu, mua/bán, trang bị.
- Cải thiện trình bày nhận thưởng và thêm phần thưởng linh hồn.
- Bao gồm shop linh hồn, mở rộng kho, thuốc, Tốc Đánh, Cái Giường và SPN Ngủ Dưới Địa Ngục của bản trước.
- Giữ màn hình ngang, tràn viền, thao tác cảm ứng và vuốt kho.

Tải `LUA-TCG-0.88.7-Android.apk`, mở file và chọn **Cập nhật**. APK dùng cùng khóa ký với bản trước, versionCode 887. Không gỡ bản cũ để giữ save.

Yêu cầu Android 6.0 trở lên, hỗ trợ ARM64 và ARMv7. Đã đối chiếu 94 file Lua với commit gốc, kiểm tra chữ ký, hiệu ứng, phần thưởng, lưu/tải, shop, kho và cảm ứng; chưa thử trên điện thoại Android thật.
